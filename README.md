# Bingo Bot for Discord

![Bingo Card Table](/card_example.png)

## Commands
`/bingo-start` Starts a new round of bingo. It loads all messages from a channel named pool and randomly picks 25 to be on the cards for the round.<br>
`/bingo-join` Registers you to participate in that round and generates your bingo card.<br>
`/bingo-card` Shows your bingo card if you are participating in a round.<br>
`/bingo-check A1` Marks A1 as completed on your bingo card.<br>
`/bingo-uncheck A1` Resets A1 your bingo card. Useful if you mark something accidentally.<br>
`/bingo-source [channel name]` Sets the channel to use as a source of the items to put on your bingo cards.

## Usage
### Setting up the pool
First you need to specify the items that'll fill the cells of your bingo card.
Those are loaded and parsed from messages in a specified channel (pool by default).
Make sure you create a channel for this purpose, and specify it with the `bingo-source [channel name]` command.<br>
You can either type them out one message at a time like this: <br>
```
item 1
```
Or you can input multiple at once line by line:<br>
```
item 1
item 2
item 3
```
You can even paste in a json list and the both'll take care of it:
```
[
    "item 1",
    "item 2",
    "item 3"
]
```
### starting a round
After you've got the pool channel filled with all the horrible stuff that can happen on a train (min. 25 items), you can start a round by typing `/bingo-start`.<br>
This'll pick 25 items from the pool channel, and start a round with them.
You can type `/bingo-join` to join the round, your card'll be generated by randomly arranging those 25 items picked for the round.
